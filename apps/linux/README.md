# apps/linux

Linux app: Rust + GTK4 + libadwaita, using the core crate directly. Distributed as a Flatpak on Flathub (primary) and an AppImage. Headless machines use `liste daemon` from the CLI crate instead.

**Phase 3. Not started.** This folder joins the Cargo workspace when the Linux GUI begins (Section 2 of `docs/ARCHITECTURE.md`).
